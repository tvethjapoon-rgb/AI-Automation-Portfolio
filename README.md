# AI-Automation-Portfolio

Static portfolio site for **Hanz Jay Apoon — AI Automation Specialist**.
Pure static (no build step): `index.html` + `style.css` + `script.js`.

## Deploy to GitHub Pages

1. Push these three files to the **repo root** of `tvethjapoon-rgb/AI-Automation-Portfolio`
   (branch `main`).
2. In repo **Settings → Pages**: Source = "Deploy from a branch", Branch = `main`, folder = `/ (root)`.
3. Site goes live at `https://tvethjapoon-rgb.github.io/AI-Automation-Portfolio/`.
